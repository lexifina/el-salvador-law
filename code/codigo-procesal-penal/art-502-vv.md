# Art. 502-VV
LAS COMUNICACIONES RELACIONADAS A LAS DILIGENCIAS INICIALES O EL TRÁMITE DE LA ASISTENCIA SE REALIZARÁN DE FORMA EXPEDITA, POR CANALES ELECTRÓNICOS Y DE FORMA DIRECTA CON LAS INSTITUCIONES PERTINENTES, ASÍ COMO CON LAS AUTORIDADES
CENTRALES DE OTRAS JURISDICCIONES.
LAS COMUNICACIONES ÚNICAMENTE PODRÁN SER A TRAVÉS DE LA VÍA DIPLOMÁTICA CUANDO ASÍ LO DISPONGA EL TRATADO APLICABLE PARA CADA CASO O ASÍ LO DETERMINE LA AUTORIDAD CENTRAL.
