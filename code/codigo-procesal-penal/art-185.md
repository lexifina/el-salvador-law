# Art. 185
Se podrá ordenar la reconstrucción del hecho, de acuerdo con las declaraciones recibidas o informaciones obtenidas y otros elementos de convicción, para comprobar si se efectuó o pudo efectuarse de un modo determinado.
La reconstrucción podrá registrarse por cualquier medio técnico, ya sea fotográfico o de grabación audiovisual.
