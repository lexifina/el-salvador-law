# Art. 321
Cuando sea necesaria la presencia del imputado, el juez dispondrá su citación, presentación o detención mediante orden escrita, que contenga los datos personales del imputado u otros que sirvan para identificarlo y la indicación del hecho que se le atribuye.
Cuando sea necesario allanar dependencias cerradas o recintos habitados para aprehender o detener a un imputado, se solicitará la correspondiente autorización judicial, salvo los casos de excepción expresamente establecidos en este Código.
