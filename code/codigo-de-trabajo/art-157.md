# Art. 157
Si el ÓRGANO EJECUTIVO no aprobare el proyecto de decreto, lo devolverá al Consejo para su reconsideración, exponiendo las razones que tenga para devolverlo. El Consejo conocerá de las observaciones del Poder Ejecutivo y hará las modificaciones que considere pertinentes, verificado lo cual, remitirá nuevamente el proyecto de decreto reconsiderado, para su oportuna aprobación.
