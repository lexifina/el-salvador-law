# Art. 261
En los estatutos de las federaciones y confederaciones pueden atribuirse a éstas las funciones de tribunal de apelación contra cualquier medida disciplinaria adoptada por una de las organizaciones afiliadas; las de dirimir las controversias que se susciten entre los miembros de un sindicato afiliado por razón de las decisiones que se adopten; y las de resolver las diferencias que ocurran entre dos o más de las organizaciones federadas.
