# Art. 486
EN LAS REUNIONES DE NEGOCIACIÓN SE PROCURARÁ LLEGAR A UN ACUERDO DIRECTO SOBRE EL PROYECTO DE CONTRATO O CONVENCIÓN. LAS SESIONES, SALVO DETERMINACIÓN EXPRESA DE LAS PARTES, SE LLEVARÁN A CABO DURANTE VEINTE DÍAS HÁBILES, CONTADOS A PARTIR DEL SIGUIENTE A AQUEL EN QUE EL PATRONO HUBIESE RECIBIDO EL PLIEGO DE PETICIONES.
