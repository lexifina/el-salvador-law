# Art. 499
Si veinticuatro horas después de notificada la resolución a que se refiere el Art. 497 lo que manifestare la parte que promovió el conflicto, no fuere el propósito de someterlo al conocimiento de árbitros, sino el de declarar la huelga o el paro, se procederá como se indica en las Secciones Séptima y Octava.
Cuando en la oportunidad señalada se desistiese, con ello terminará el conflicto.
