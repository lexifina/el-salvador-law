# Art. 348
Para el cálculo de las indemnizaciones, si el patrono suministraba a la víctima prestaciones complementarias, tales como alimentación, habitación, etc., el salario básico se aumentará hasta en un treinta por ciento como máximo por todas ellas, atendidas las circunstancias, a menos que el patrono continuare proporcionando dichas prestaciones a la víctima.
