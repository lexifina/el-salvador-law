# Art. 1463
Será nulo el seguro para el caso de muerte de una persona declarada en estado de interdicción, o de un menor de catorce años; salvo que el asegurante sea un ascendiente o descendiente o el cónyuge del asegurado.
En los seguros de supervivencia de las personas a que se refiere este artículo, podrá pactarse la devolución de las primas para el caso de muerte.
