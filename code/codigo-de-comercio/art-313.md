# Art. 313
El retiro parcial o total de aportaciones de un socio deberá notificarse a la sociedad y no surtirá efecto hasta el fin del ejercicio anual en curso, si la notificación se hace antes del último trimestre de dicho ejercicio; y hasta el fin del ejercicio siguiente, si se hiciere después.
Esta notificación deberá ser judicial o por acta notarial.
