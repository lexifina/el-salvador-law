# Art. 936
El Juez, si se otorga garantía suficiente, ordenará la suspensión de los derechos que el título confiera; autorizará al solicitante para realizar los actos conservativos de tales derechos y, con las restricciones y requisitos que el propio Juez señale, le facultará para hacer valer aquéllos que tengan señalado para su ejercicio un término que se cumpla mientras dure el procedimiento.
